# Support

This document explains where to go for help with EHDS Relay.

## Supported versions

EHDS Relay is pre-release. Only the latest code on `main` is supported.

## Documentation

Start with the [README](README.md), which covers the project layout, running
it locally and the main API. [CONTRIBUTING.md](CONTRIBUTING.md) covers
development.

## Asking a question or getting help

Please use [GitHub issues](https://github.com/EHDS-Open-Source/ehds-relay/issues)
for questions, bug reports and feature requests. Search existing issues first
to avoid duplicates, and use the appropriate template.

When reporting a problem, please include:

- The commit of EHDS Relay you are running
- Your environment (for example operating system, docker and kind versions)
- Steps to reproduce the issue
- What you expected to happen and what actually happened
- Relevant logs or error messages (with any sensitive data removed)

## Security issues

Please **do not** open a public issue for security vulnerabilities. See
[SECURITY.md](SECURITY.md) for how to report these responsibly.

## Contacting the team directly

For questions that are not suited to a public issue, you can reach the Aridhia
Open Source team at **opensource@aridhia.com**.

## Contributing

If you would like to contribute a fix or improvement rather than just report a
problem, see [CONTRIBUTING.md](CONTRIBUTING.md).
